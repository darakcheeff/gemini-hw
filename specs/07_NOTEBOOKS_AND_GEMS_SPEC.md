# Спецификация 07: Блокноты (Notebooks) и персональные ассистенты (Gems)

Спецификация интеграции NotebookLM и Gems из веб-интерфейса Gemini.

---

## 1. Персональные ассистенты (Gems)
- **Эндпоинт получения**: `batchexecute` RPC с ID `Gems` или извлечение из начальной разметки `WIZ_global_data`.
- Каждый Gem содержит:
  - Идентификатор `id`.
  - Заголовок `title` и описание `description`.
  - Системную инструкцию `instructions` (системный промпт модели).
- При выборе Gem активируется соответствующий системный контекст диалога.

## 2. Блокноты (Notebooks)
- **Привязка проекта**:
  В запросе `StreamGenerate` блокнот привязывается через метаданные:
  - Поле 20: `notebooks/<notebookId>`.
  - Поле 41: массив `xBd` метаданных.
  - Поле 105: `superprojectId = notebooks/<notebookId>`.
- **Источники блокнота**:
  - Файлы Google Drive, текстовые заметки и веб-ссылки прикрепляются к блокноту и учитываются моделью при генерации ответов.
