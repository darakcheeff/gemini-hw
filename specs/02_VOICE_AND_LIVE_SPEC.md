# Спецификация 02: Голосовой ввод и режим Gemini Live

Спецификация реализации двух голосовых режимов с обеспечением 100% автономности без GMS.

---

## 1. Режим 1: Набор текста голосом (Кнопка микрофона в строке ввода)

### Оригинальное поведение (Google):
- Нажатие на микрофон вызывает Google Speech Services (`RecognitionService`).
- Голос переводится в текст в реальном времени и подставляется в строку ввода.

### Автономная реализация без GMS:
1. Захват звука осуществляется нативным Android API `MediaRecorder` в формате AAC (`audio/mp4`, 44.1 kHz, 64 kbps).
2. Запись аудиофайла сохраняется во временный кэш приложения (`cacheDir`).
3. При завершении записи файл аудиопотока отправляется напрямую на сервер Gemini через Google Scotty (`push.clients6.google.com/upload/`) с директивой транскрибации.
4. Расшифрованный текст немедленно подставляется в строку ввода `inputText`.
5. Пользователь может отредактировать, дополнить или отправить сообщение.

---

## 2. Режим 2: Gemini Live (Живой hands-free диалог)

### Оригинальное поведение (Google):
- Вызывает активность `com.google.android.apps.search.assistant.surfaces.voice.robin.main.MainActivity`.
- Полноэкранный темный экран с пульсирующей звуковой волной, поддерживающий непрерывный двусторонний голосовой диалог.

### Автономная реализация без GMS:
1. Полноэкранный встроенный компонент `GeminiLiveDialog` прямо внутри нашего APK.
2. Круглая анимированная сфера пульсирует с реальной амплитудой голоса пользователя (`getMaxAmplitude()`).
3. Автоматическое определение окончания фразы (VAD / 1.8 с тишины) или ручное нажатие «Отправить».
4. Аудио отправляется в мультимодальный эндпоинт `StreamGenerate` с вложением `kind = 2` (audio).
5. Ответ модели стримится на экран и одновременно озвучивается через нативный `TextToSpeech` (PicoTTS / Huawei Celia TTS / RHVoice).
6. Как только синтез речи завершился (`onDone`), микрофон автоматически включается снова для следующей фразы без участия рук пользователя.
