# Полный план тестирования автономного клиента Gemini (без GMS)

Данный план предназначен для систематической и всесторонней проверки работоспособности каждой функции автономного клиента Gemini на устройствах Huawei, Honor, а также любых de-Googled AOSP / HarmonyOS прошивках без наличия сервисов Google (GMS).

---

## 0. Условия тестирования (GMS-Free окружение)
Перед началом всех тестов убедиться, что на целевом устройстве отключены или удалены все компоненты Google:
```bash
adb shell pm disable-user com.google.android.gms
adb shell pm disable-user com.google.android.gsf
adb shell pm disable-user com.android.vending
adb shell pm disable-user com.google.android.googlequicksearchbox
adb shell pm disable-user com.google.android.apps.bard
```
Проверка статуса:
```bash
adb shell pm list packages -d | grep -E 'google|gms|vending'
```

## 1. Авторизация и сессия пользователя
- [ ] **1.1. Сохранение сессии Google**:
  - При установке обновлений поверх (`adb install -r`) аккаунт и куки (`__Secure-1PSID`, `__Secure-1PSIDTS`) сохраняются.
  - Приложение стартует сразу в активном чате без принудительного повторного входа.
- [ ] **1.2. Вход без GMS (LoginActivity)**:
  - Форма авторизации в чистом `WebView` (с замаскированным десктопным / мобильным Chrome User-Agent).
  - Ручной ввод Cookie через кнопку «Куки» в случае двухфакторной аутентификации.
  - Автоматическое извлечение токенов `SNlM0e` (at), `FdrFJe`, `cfb2h`, `qKIAYe` (Push-ID) и `Ylro7b` (Pctx) со страницы `gemini.google.com/app`.

## 2. Модели и настройки чата
- [ ] **2.1. Динамический список моделей**:
  - Выпадающий список моделей (`Gemini 2.5 Flash`, `Gemini 2.5 Pro`, `Gemini 3.8 Flash`, превью-модели) загружается напрямую с сервера Google через RPC `otAQ7b`.
  - Модели переключаются на лету, индикатор текущей модели в верхней панели обновляется.
- [ ] **2.2. Уровень размышлений (Thinking Level)**:
  - Переключение режимов размышлений (Низкий, Высокий, Без размышлений).
  - Модель выводит скрытые цепочки рассуждений (`thoughts`) в отдельном раскрывающемся блоке.

## 3. Отправка и рендеринг текстовых сообщений
- [ ] **3.1. Базовый текстовый обмен**:
  - Ввод текста в нижнюю строку «Спросить Gemini».
  - Отправка по нажатию на стрелку или клавишу Enter.
  - Потоковый стриминг ответа (`StreamGenerate 200`).
- [ ] **3.2. Нативный Markdown-парсер**:
  - Заголовки H1–H6.
  - Жирный, курсивный текст, зачеркивание, цитаты (`>`).
  - Маркированные и нумерованные списки.
  - Блоки кода с подсветкой синтаксиса и кнопкой «Копировать код».
  - Таблицы с границами ячеек и выравниванием.

---

## 4. Режим документов Canvas
- [ ] **4.1. Переключатель режима Canvas**:
  - Кнопка в верхней панели (`Режим Canvas`) переключает состояние режима (активен/неактивен).
- [ ] **4.2. Автоматическое всплытие документа**:
  - При генерации программного кода или структурированного текста автоматически открывается полноэкранный диалог `CanvasDialog`.
- [ ] **4.3. Вкладки диалога Canvas**:
  - **Предпросмотр**: красивый отформатированный код с кнопками шеринга и копирования.
  - **Редактор**: поле редактирования текста пользователем вручную.
- [ ] **4.4. Интерактивные чипы AI-правок**:
  - Нажатие на чипы (`🔍 Найти ошибки`, `📝 Сделать короче`, `💬 Добавить комментарии`, `👔 Деловой стиль`, `🔄 Переписать`).
  - Gemini получает контекст документа и отправляет обновленную версию, документ в Canvas заменяется автоматически.

## 5. Автономные голосовые функции (Zero GMS)
- [ ] **5.1. Кнопка «Микрофон» (набор текста голосом)**:
  - Нажатие на микрофон запускает нативный `MediaRecorder` (`audio/mp4`, AAC).
  - Иконка меняется на красный индикатор записи.
  - Повторное нажатие останавливает запись и отправляет аудио в Gemini на транскрибацию.
  - Расшифрованный текст появляется в поле ввода без вызова системного Google SpeechRecognizer.
- [ ] **5.2. Автономный экран «Gemini Live»**:
  - Нажатие на иконку звуковой волны открывает полноэкранный экран `GeminiLiveDialog` внутри нашего приложения.
  - Анимированная сфера пульсирует в такт громкости голоса пользователя (`getMaxAmplitude()`).
  - Автоматическое определение паузы в речи (VAD) или ручная отправка по кнопке «Отправить».
  - Получение стримингового ответа от Gemini и автоматическое чтение вслух через `TtsManager`.
  - После окончания ответа микрофон автоматически включается снова для следующего вопроса (Hands-Free цикл).
- [ ] **5.3. Озвучивание сообщений (TTS Read Aloud)**:
  - Кнопка с динамиком на пузыре сообщения модели воспроизводит ответ через системный Android `TextToSpeech` (PicoTTS / Huawei Celia / RHVoice).
  - Повторный клик прерывает воспроизведение.

## 6. Загрузка вложений и протокол Google Scotty
- [ ] **6.1. Меню вложений (`+`)**:
  - «Галерея и Google Фото» (`GetMultipleContents`)
  - «Живая камера» (`FileProvider` + фотосъемка)
  - «Файлы и Google Диск» (`OpenMultipleDocuments`)
  - «Скриншот экрана» (автоматический поиск последнего скриншота в `MediaStore`)
- [ ] **6.2. Превью прикрепленных файлов**:
  - Горизонтальная лента над строкой ввода с миниатюрами и кнопками удаления (`✕`).
- [ ] **6.3. Загрузка через Google Scotty Push Protocol**:
  - Инициализация сессии на `https://push.clients6.google.com/upload/` с заголовками `Push-ID` и `X-Client-Pctx`.
  - Финализация загрузки сырых байтов файла.
  - Передача серверного пути (`/contrib_service/ttl_1d/...`) в слот 3 запроса `StreamGenerate`.
  - Gemini учитывает содержимое вложения в ответе.

## 7. Генерация и отображение изображений (Imagen 3)
- [ ] **7.1. Запрос генерации изображения**:
  - Отправка запроса: «Создай изображение [описание]» (при выключенном режиме Canvas).
- [ ] **7.2. Извлечение и рендеринг изображений**:
  - Извлечение прямых ссылок `googleusercontent.com` и Markdown-картинок `![alt](url)`.
  - Отображение изображений через Coil `AsyncImage` с скругленными углами и индикатором загрузки.
  - Нажатие на изображение открывает полноэкранный просмотр с зумом.

## 8. Управление диалогами (TopAppBar & Drawer)
- [ ] **8.1. Боковое меню (Drawer)**:
  - Список всех недавних бесед (до 50 чатов через `MaZiqc`).
  - Переключение между чатами с мгновенной подгрузкой истории (`hNvQHb`).
  - Закрепление чатов (`isPinned`).
- [ ] **8.2. Верхняя панель активного чата**:
  - **Поделиться**: открытие нативного Android Share Sheet.
  - **Переименовать**: всплывающий диалог с сохранением нового названия на сервере.
  - **Удалить**: подтверждение удаления, очистка из списка и возврат к новому чату.
  - **Новый чат (`+`)**: мгновенная очистка экрана и старт новой беседы.
- [ ] **8.3. Ветвление диалога («Создать ветвь в новом чате»)**:
  - Нажатие на иконку ветвления на сообщении клонирует историю до этой точки в новый диалог.

## 10. Ассистент с анализом экрана (Power Button / Assist Gesture)
- [ ] **10.1. Вызов ассистента**:
  - Запуск службы `VoiceInteractionService` / `AssistantActivity` по жесту ассистента или команде `am start`.
  - Автоматический захват скриншота экрана без GMS.
- [ ] **10.2. Плавающий оверлей ассистента**:
  - Отображение миниатюры захваченного экрана.
  - Быстрые чипы: `🔍 Что на экране?`, `🌐 Перевести текст`, `💡 Суть вкратце`, `📋 Извлечь данные`.
  - Нажатие на чип отправляет скриншот и вопрос напрямую в Gemini и закрывает оверлей.
