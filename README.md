# Gemini Client for Huawei Devices (Non-GMS)

Автономный, легковесный и быстрый клиент Google Gemini для устройств Huawei (EMUI / HarmonyOS) и любых Android-устройств без установленных Google Mobile Services (GMS).

---

## 🎯 Ключевые возможности

- **100% независимость от GMS**: Приложение не требует сервисов Google Play, Google App или сторонних виртуализаторов (GBox, microG).
- **Синхронизация с официальным сайтом**:
  - Полный доступ к единой истории чатов с `gemini.google.com`.
  - Поддержка создания новых диалогов, удаления и переименования.
  - Функция **«Создать ветвь в новом чате»** из любого сообщения.
  - **Редактирование сообщений** прямо в цепочке диалога с генерацией альтернативных ответов.
- **Динамический список моделей**:
  - Модели (Gemini 2.0 Flash, 1.5 Pro, Flash Thinking и т.д.) не захардкожены, а подгружаются динамически с сервера Google.
- **Прямой голосовой ввод**:
  - Запись и прямая отправка аудио-чанков в Gemini без использования системного Google SpeechRecognizer.
- **Интерактивный Canvas**:
  - Открытие, просмотр и редактирование сгенерированного кода и документов прямо в приложении.
- **Блокноты (Gems) и Задачи (Spark)**:
  - Выбор и активация персонализированных блокнотов/инструкций.
  - Отслеживание пошаговых сценариев задач в режиме Spark.
- **Вложения и генерация медиа**:
  - Просмотр и нативное скачивание сгенерированных изображений (Imagen 3) и файлов.

## 🏗 Структура проекта

Проект разбит на 3 модуля:

1. **`:core`** (Общий движок):
   - Экстрактор и менеджер сессионных токенов (`__Secure-1PSID`, `SNlM0e`).
   - Сетевой клиент к internal RPC `batchexecute` Google Gemini.
   - Низкоуровневый аудио-рекордер (PCM/WAV) для прямого голосового ввода.
   - Модели данных (модели, чаты, сообщения, вложения, canvas, gems, spark).
2. **`:app-native`** (Основной вариант):
   - Чистый Jetpack Compose (Material 3).
   - Минималистичный и легкий интерфейс без тяжелых визуальных эффектов и фонов.
   - Минимальная версия Android: **Android 9.0 (API 28)**.
3. **`:app-web`** (Резервный вариант):
   - Сверхлегкий нативный шелл с оптимизированным WebView, аппаратным ускорением, нативным загрузчиком файлов и доступом к микрофону.

## 🚀 Сборка и CI/CD (GitHub Actions)

Сборка полностью автоматизирована в облаке GitHub Actions:

- При каждом коммите в ветку `main` собираются оба APK.
- Используются секреты репозитория для подписи релизным ключом:
  - `KEYSTORE_BASE64`
  - `KEYSTORE_PASSWORD`
  - `KEY_ALIAS`
  - `KEY_PASSWORD`
- Готовые подписанные APK сохраняются в артефактах GitHub Actions и релизах.

### Локальная сборка:
```bash
./gradlew assembleRelease
```
Либо раздельно:
```bash
./gradlew :app-native:assembleRelease
./gradlew :app-web:assembleRelease
```

## 🔒 Безопасность и вход

Авторизация осуществляется через изолированный системный веб-компонент с корректным User-Agent Chrome, что исключает блокировку со стороны Google («Browser or app may not be secure»). Сессионные токены хранятся исключительно на вашем устройстве.
